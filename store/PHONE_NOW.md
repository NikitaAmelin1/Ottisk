Игра уже на GitHub Pages: https://nikitaamelin1.github.io/Ottisk/

## С телефона (можно прямо сейчас)

1. Открой ссылку в Chrome / Safari.
2. **Ещё → С телефона** в игре:
   - скопируй ссылку другу
   - установи на домашний экран
   - отметь короткий QA-чеклист
3. Сыграй 2–3 забега: onboarding, пауза (свернуть браузер), «Ещё раз», поделиться результатом.
4. Сохрани прогресс: **Ещё → Прогресс → Код переноса** (или файл).
5. Включи **одна рука**, если неудобно тянуться.
6. Проверь локальный рейтинг после забега (без облака).
7. В GitHub Mobile можно смотреть PR и Merge — если нужно.

Облако (друзья / синк между телефонами) заработает только после Worker URL — это уже шаг с ПК.
