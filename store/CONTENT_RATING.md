# Google Play Content Rating (IARC)

Пройдите анкету **App content → Content ratings**.

Рекомендуемые ответы для ОТТИСК (аркада на выживание без крови/сцен насилия людей):

| Тема | Рекомендация |
| --- | --- |
| Насилие | Нет реалистичного насилия / нет крови. Абстрактные «охотники» в океане — отметить минимальный уровень, если спрашивают про «fantasy violence». |
| Сексуальный контент | Нет |
| Ненормативная лексика | Нет |
| Контролируемые вещества | Нет |
| Азартные игры | Нет (in-app purchases — это покупки контента, не gambling) |
| User-generated content | Нет публичного чата; кастомный герой рисуется локально |
| Online users | Опциональный рейтинг дня / друзья при облаке — указать «Users interact» только если cloud включён по умолчанию. Сейчас cloud выключен → обычно **No**. |
| Share location | Нет |
| Digital purchases | **Да** — Google Play Billing (следы, герои, стартовый пак, tips) |

Ожидаемый возрастной рейтинг: **PEGI 3 / Everyone** (уточняется анкетой IARC).

Сохраните сертификат rating в Console и приложите к релизу.
